# ReSieve

Regram 的本机中文推广意图分类模型，基于 [MiniRBT-H256](https://huggingface.co/hfl/minirbt-h256) 微调。当前模型版本为 **1.0.0**，对应 Regram **13.2 / b34659** 使用的权重（内部版本 `2026-11-16.9`）。

## 模型文件

| 文件 | 格式 | 大小 |
| --- | --- | --- |
| [coreml/ReSieve.mlmodel](coreml/ReSieve.mlmodel) | Core ML，FP16 权重 | 20,571,001 字节 |
| [pytorch/model.safetensors](pytorch/model.safetensors) | PyTorch / Transformers，FP32 权重 | 41,394,928 字节 |

`pytorch/` 包含本地加载所需的配置和词表。架构为 6 层 Transformer、隐藏维度 256，共 10,345,730 个参数。两种格式来自同一检查点；Core ML 文件与 b34659 构建源模型字节一致。使用 `shasum -a 256 -c SHA256SUMS` 核对文件。

## 推理约定

- 输出顺序为 `content`、`promotion`；推荐片段候选阈值为 **0.962**。该数字是决策阈值，不是准确率，也不代表超过阈值即可删除整条消息。
- 使用配套 BERT WordPiece 词表。输入先做 NFKC、小写、去除 Unicode `Cf/Mn/Me/So/Sk` 类字符，将 URL、用户名、五位以上数字分别规范化为「链接」「用户」「数字」，去除汉字间空白并合并其他空白。精确替换表达式见 [model.json](model.json)。规范化仅用于推理，不能将规范化文本的偏移直接用于原消息裁剪。
- 每个窗口 128 token，含 `[CLS]` / `[SEP]` 与补齐；内容窗口重叠 16 token，最后一个窗口从末尾向前对齐至完整的 126 个内容 token。最多 8 个窗口，使用所有窗口推广概率的最小值。超限保留／不判定，不静默截断。
- Core ML 输入是 `input_ids` 和 `attention_mask`，均为 `Int32[1,128]`；输出名为 `probabilities`。采用 **CPU_ONLY**，其他计算单元未经本版本概率一致性验收。

这是文本分类器。Regram 对混合消息的裁剪还依赖分段、上下文、实体边界、结构规则和个人纠错；仅加载权重不会自动得到完整的应用过滤行为。图片、视频、音频和纯表情图像不在识别范围内，未知广告可能漏判，正常内容也可能误判。

## 评估范围

公开垃圾信息历史基准 6,663 条：Precision **97.33%**、Recall **33.34%**、正常类误报率 **0.95%**。该基准经过多轮观察，标签与应用的广告政策不同，不能换算为频道广告覆盖率。作者编写的域内选择集为正常 30/30 保留、推广 23/25 识别。

应用层 931 条已审阅开发回归通过，其中 4 条依赖既有个人纠错；其余也依赖应用策略。包含参与迭代的样本和重复模板，不能视为模型独立测试或未知样本准确率。Core ML FP16 转换的 100 条向量最大概率误差约 0.00337。
