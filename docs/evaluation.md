## Regram 显示回归

这里检查的是模型和客户端共同处理后的消息，不能算作模型单独的成绩。

- 旧开发集 939 条消息：814 条包含正常文字，**`normalCut = 0`**；575/575 条混合消息完整移除广告；122/125 条纯广告隐藏；按钮错误 1 条（`phone-34659-139`，3 汉字语言边界）。
- 新增样本集 227 条人工核对消息（另 3 条歧义样本单独排除）：153 条包含正常文字，**`normalCut = 0`**；99/99 条混合消息完整移除广告；71/74 条纯广告隐藏（含 1 条超过 8 窗/1024 token 上限的长文案）；按钮错误 1 条（`new-34664-069`）。
- 另有新增三批去重未覆盖样本集 418 条与 281 条，经原生 `SemanticHarness` 验证：先前误判的正常服务/科普/通知文案全部保留，新补充推广与返利话术可稳定命中。

## 导出一致性

同一检查点导出了 FP32 PyTorch 和 FP16 Core ML 权重。100 个转换输入的最大概率差为 `0.0025036633014678955`，通过小于 `0.01` 的验收；另有 12 个长文本窗口边界检查。原生 Core ML 与导出参考概率的最大差为 0；离线 PyTorch 重新加载（`local_files_only=True`）最大差为 `0.002505362033843994`。

版本、文件摘要和来源在 [model.json](../model.json)、[provenance.json](../metadata/provenance.json)、[verification.json](../metadata/verification.json) 和 [SHA256SUMS](../SHA256SUMS) 中。

## 边界

这仍是中文文字分类器。它不读取图片像素、视频或音频，也不覆盖超过 1024 个 token（8 个窗口）或不足 4 个有效汉字边界的内容。客户端会额外保护正常正文、引用和代码；新包的真机端到端表现仍需在设备上复测。
